# GA-I1: Customer一覧へ最終更新日時を表示する

Customer一覧テーブルへ各顧客の最終更新日時を追加してください。

完了条件: 最終更新日時をAsia/Tokyoで表示する。 / 一覧APIの既存レスポンス互換性を維持する。 / 顧客一覧テーブルへ更新日時列を追加する。 / 不要なDB変更を行わない。 / UIテストと型検査が成功する。

制約: 日時の保存形式とPrisma schemaを変更しない。 / 顧客詳細画面の表示仕様を変更しない。

確認: `pnpm test:customer` / `pnpm typecheck`

原因と影響範囲を確認して必要最小限の変更を行い、確認結果と残る問題を報告してください。外部状態や不足情報により安全に完了できない場合は、変更を広げず理由を報告してください。
