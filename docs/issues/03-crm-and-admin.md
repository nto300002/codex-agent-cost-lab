# M3: CRM・管理機能

## ISSUE-010: Deal管理を実装する

- 種別: feature
- 依存: ISSUE-007、ISSUE-009
- 状態: 実装済み
- 目的: 顧客に紐づく商談をステージと担当者付きで管理する。

### スコープ

- Dealドメイン、API、UI
- 一覧、詳細、作成、更新
- ステージ、担当者、顧客の絞り込み
- 金額の整数管理と表示

### 受入条件

- ステージ遷移と必須項目を検証する。
- MEMBERは担当外Dealを更新できない。
- UIとAPIで同じステージ定義を使用する。
- Customer詳細から関連Dealを確認できる。

### 検証

```bash
pnpm test:deal
```

## ISSUE-015: AuditLog基盤と管理画面を実装する

- 種別: feature
- 依存: ISSUE-007、ISSUE-013
- 目的: 主要操作を追跡し、ADMINが閲覧できる基盤を作る。

### スコープ

- AuditLog repositoryと記録サービス
- 認証、ユーザー管理等の基準操作への記録
- ADMIN専用一覧・詳細
- 秘密情報の除外

### 受入条件

- actor、action、entity type、entity id、timestampを記録する。
- パスワード、セッション、Cookie、不要な個人情報を記録しない。
- ログ記録の有無が業務トランザクションと不整合にならない。
- GC-I1で適用範囲を拡張できる設計になっている。

### 検証

```bash
pnpm test:audit
```
